# 侧栏收起/展开布局稳定性设计

## 1. 背景与目标

管理后台侧栏支持收起和展开。当前侧栏收起后再次展开时，导航项的纵向高度和分组间距可能发生变化，导致同一页面出现两种展开布局。

目标是固定为紧凑样式：无论首次进入页面，还是经过“收起 → 展开”，展开后的侧栏都保持相同的导航项高度、分组间距和控制区域布局。侧栏的路由、权限过滤、当前项高亮和收起/展开能力保持不变。

## 2. 设计决策

采用显式固定纵向尺寸的方案。展开状态下：

- 导航项使用固定的 36px 高度，避免由内容或网格布局重新计算高度。
- 导航项之间保持 3px 间距，分组之间保持 15px 间距；导航容器使用从顶部开始的内容布局，不拉伸子项。
- 收起状态只改变侧栏宽度、品牌文字、分组标题和导航文字的可见性。
- 保留现有侧栏宽度过渡动画，不通过事件回调或临时状态强制恢复样式。

这样可以从布局约束上保证两次展开结果一致，而不是依赖切换时机或补偿性重置。

## 3. 影响范围

主要修改：

- `src/components/layout/Sidebar.vue`：固定侧栏导航的纵向尺寸和布局行为。
- `src/components/layout/__tests__/Sidebar.spec.ts`：验证导航结构、切换行为和紧凑布局约束。

不修改：

- 路由与权限判断。
- 管理页面内容区域。
- 侧栏视觉颜色、品牌内容和现有宽度值。

## 4. 行为与边界

- 初始展开时显示紧凑导航布局。
- 点击收起后隐藏品牌名称、分组名称和导航文本，仅保留图标/标记。
- 再次展开后恢复完整文字，并使用与初始状态完全相同的导航项高度和间距。
- 当前路由高亮在切换前后保持不变。
- 权限过滤后的分组数量变化不影响单个导航项的固定高度。
- 窄屏媒体查询继续沿用现有宽度规则。

## 5. 测试与验收

组件测试覆盖：

- 初始状态显示展开导航。
- 收起后隐藏展开文本，展开后恢复文本。
- 切换前后导航项数量、路由和当前项高亮保持一致。
- 组件样式包含固定导航项高度、固定分组间距和不拉伸导航容器的约束。

验收标准：

1. 首次进入和收起后重新展开时，侧栏均呈现第一张效果图的紧凑样式。
2. 导航项不会因为侧栏状态切换而变为宽松的大高度布局。
3. 页面主内容区域、路由跳转和权限控制不受影响。
4. 在 Node 20.20.2 下通过 `npm run test`、`npm run type-check` 和 `npm run build`。
5. 在真实浏览器中完成展开 → 收起 → 展开流程检查。
