# 供应商超时默认值调整设计

## 目标

新建供应商时，将连接超时默认值从 `10` 调整为 `10000`，读取超时默认值从 `60` 调整为 `120000`。编辑供应商时，如果后端返回空超时值，也使用相同的新默认值。

## 实现范围

- 更新供应商表单初始化值和重置值。
- 更新编辑表单对空超时值的回退值。
- 调整连接超时和读取超时输入框的最大值，使新默认值可以正常显示和提交。
- 增加测试，验证新建表单提交 `10000/120000`。

## 行为与约束

- 编辑时后端返回的非空超时值保持不变。
- 连接超时和读取超时仍保留现有最小值 `1`。
- 输入框最大值分别调整为 `10000` 和 `120000`，不引入无上限输入。
- 不修改供应商接口类型、后端 API 或其他页面。

## 验证

使用项目现有测试命令验证供应商管理测试，并运行 Node 20.20.2 下的类型检查和生产构建。
