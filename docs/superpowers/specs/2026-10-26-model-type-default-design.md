# 新建模型默认类型设计

## 目标

新建模型表单的“模型类型”默认值从 `chat` 改为 `CHAT`，以符合后端模型类型约定。

## 范围

- 修改 `src/views/ai/ModelManagementView.vue` 中新建表单的初始值和重置值为 `CHAT`。
- 新建表单提交时继续原样提交 `modelType`，不增加额外转换。
- 编辑模型时继续使用后端返回的 `modelType`，不强制转大写。
- 不修改 API、类型定义、列表展示或其他表单默认值。

## 实现方案

更新 `form` 的默认对象和 `resetForm()` 使用的默认对象，使两条新建入口都得到 `CHAT`。保留 `openEdit()` 对后端值的赋值逻辑，确保编辑行为不受影响。

## 验证

在模型管理视图测试中，打开新建表单并提交最小有效数据，断言 `createModel` 收到的 `modelType` 为 `CHAT`。现有模型加载、编辑和布尔字段转换测试继续通过。
