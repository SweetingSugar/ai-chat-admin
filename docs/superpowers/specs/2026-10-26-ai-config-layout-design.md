# AI 配置管理页面布局设计

## 1. 背景与目标

供应商管理和模型管理页面当前由 `AiConfigLayout` 额外渲染“AI 配置”标题、说明和页面页签，导致页面顶部与用户管理页面结构不一致。本次调整移除这层额外内容，使两个 AI 管理页面直接从各自的 `PageHeader` 开始。

## 2. 范围与方案

采用保留父级布局、简化布局内容的方案：

- 保留 `AiConfigLayout.vue` 作为供应商和模型路由的父级容器。
- 删除“AI 配置”标题、说明、供应商/模型页签，以及对应的路由切换逻辑和无用样式。
- 父级布局仅渲染 `<RouterView />`。
- 保留现有嵌套路由、权限校验、侧边栏导航、供应商和模型页面的 `PageHeader`、筛选、表格及全部操作。

## 3. 交互与数据流

本次不改变任何业务数据流。访问 `/ai/providers` 或 `/ai/models` 时，路由和权限行为保持不变；侧边栏仍负责两个页面之间的导航，页面内部不再显示顶部 AI 配置页签。

## 4. 测试与验收

1. 更新或补充布局测试，确认 AI 配置标题和页签不再渲染，子路由内容仍能渲染。
2. 运行 AI 供应商和模型管理页面相关测试。
3. 运行 `npm run type-check`、`npm run test` 和 `npm run build`。
4. 在浏览器中确认供应商和模型页面与用户管理页面一样，从页面标题直接开始，且侧边栏跳转、刷新、新建、编辑和删除功能不受影响。

## 5. 非目标

本次不调整供应商和模型页面的业务逻辑、接口、表格、筛选器、权限定义、侧边栏结构或整体管理页面样式，也不取消 AI 路由父级结构。
